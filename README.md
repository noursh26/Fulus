# 💰 Fulus - فُلُس 💰
## مدير المصاري الذكي الاحترافي v2.1

تطبيق إدارة مالية شخصية متقدم مبني بـ Flutter مع دعم كامل للغة العربية واتجاه RTL.

---

## ✨ الميزات الرئيسية

### 💱 دعم متعدد العملات
- **29 عملة مدعومة** بما فيها العملات العربية والعالمية
- أسعار صرف مدمجة مع إمكانية التحويل الفوري
- **🆕 أسعار صرف مخصصة** - تحديد أسعارك الخاصة لكل عملة
- محول عملات متكامل مع واجهة احترافية
- تحويل تلقائي للأرصدة للعملة الرئيسية

### 🏦 إدارة الحسابات المتقدمة
- أنواع متعددة للحسابات (نقدي، بنكي، بطاقة ائتمان، محفظة إلكترونية، استثمار، ادخار)
- إمكانية إخفاء الحسابات من الإجمالي
- أرشفة الحسابات
- أيقونات وألوان مخصصة
- حد ائتمان ورصيد مستهدف
- ملاحظات لكل حساب

### 📊 المعاملات الذكية
- تسجيل الدخل والمصروفات
- تصنيفات متعددة مع إيموجي
- معاملات متكررة (يومي، أسبوعي، شهري، سنوي)
- إمكانية تعديل المعاملات
- إضافة ملاحظات ومستفيد وموقع
- وسوم للتصنيف المتقدم

### 📈 تقارير وإحصائيات
- ملخص شهري للدخل والمصروفات
- رسوم بيانية تفاعلية (دائرية وشريطية)
- إحصائيات متقدمة مع تحليل الفترات
- توزيع المصاريف حسب التصنيف
- اتجاهات المصروفات

### 🎨 تصميم احترافي
- **تصميم زجاجي (Glassmorphism)** عصري
- **ناف بار عائمة** مع زر إضافة مركزي
- دعم كامل لـ **RTL** واللغة العربية
- ألوان وتدرجات جذابة
- أنيميشن سلسة

### 🔧 ميزات إضافية
- تصدير البيانات إلى Excel
- الوضع الداكن والفاتح
- ميزانيات للتصنيفات
- تحويلات بين الحسابات
- بحث وفلترة متقدمة

## 📱 نظرة عامة

**Fulus** هو تطبيق إدارة مالية شخصية احترافي مبني بـ Flutter. يساعدك على تتبع مصاريفك ودخلك، إدارة حساباتك المتعددة، وتحليل إنفاقك بطريقة سهلة وجميلة.

## ✨ المميزات

- 🏦 **إدارة حسابات متعددة** - أضف حسابات بعملات مختلفة
- 💸 **تتبع المعاملات** - سجّل دخلك ومصاريفك بسهولة
- 📊 **تقارير ورسوم بيانية** - تحليل شامل لإنفاقك
- 🎯 **ميزانية شهرية** - حدد ميزانيتك وتابع التزامك بها
- ↔️ **تحويل بين الحسابات** - مع دعم أسعار الصرف
- 📤 **تصدير إلى Excel** - صدّر بياناتك بسهولة
- 🌙 **الوضع الداكن** - واجهة أنيقة ومريحة للعين
- 🌍 **دعم عملات متعددة** - USD, EUR, SYP, SAR, AED, TRY, وأكثر
